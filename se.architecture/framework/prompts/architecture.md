# Agent 提示词模板

## 从输入资料生成初版架构

```text
你是架构文档编译 Agent。

输入是项目 PRD、源码、README、接口文档和现有文档。
请生成 ARCHITECTURE 系列文档。

要求：
1. 区分稳定架构与易变需求细节。
2. 顶层 ARCHITECTURE.md 只保留稳定架构基线。
3. 模块细节下沉到 modules/*.md。
4. 明确实体、状态机、权限模型、模块边界、不变量。
5. 区分通用能力和业务能力。
6. 对无法确定的信息标记为“待确认”，不要臆造。
7. 输出 source-map，说明每个关键结论来自哪个输入来源。
8. 修改后运行架构检查脚本。
```

## 从源码反向提取架构

```text
请从当前仓库源码反向提取架构事实。

重点识别：
- 包结构和模块边界
- Controller / Service / Repository 职责
- 数据库实体和核心关系
- 权限、安全、审计、文件、通知等通用能力
- 状态字段和状态流转
- 外部系统依赖

输出：
1. 与现有 ARCHITECTURE 文档一致的事实。
2. 源码存在但架构文档缺失的事实。
3. 架构文档声明但源码未体现的差异。
4. 建议更新的文档位置。
```

## 维护现有架构

```text
请根据本次需求变化维护 ARCHITECTURE 系列文档。

要求：
1. 只修改受影响的最小文档集合。
2. 不把页面细节、接口参数全集写入顶层架构。
3. 如果影响模块边界或不变量，更新 project/ARCHITECTURE.md。
4. 如果只是模块内部规则，更新对应 modules/*.md。
5. 如有关键取舍，新增或更新 decisions/*.md。
6. 更新 source-map.md。
7. 运行 npm run architecture:check。
```
